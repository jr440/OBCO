STL & 3MF File Preparation Guide

A clean model gives you faster turnaround, better print quality, and more accurate instant pricing.

Model Integrity

  • Export as a watertight manifold mesh (no holes).
  • Remove non-manifold edges and intersecting surfaces.
  • Avoid flipped normals and duplicate shells.
  • If multi-body, combine only parts you want printed as one piece.

Scale & Units

  • Use millimeters as your export unit.
  • Confirm critical dimensions before upload.
  • Apply transforms and reset scale in CAD before export.
  • Include tolerance in mating parts (typically 0.2mm to 0.4mm for FDM).

Printability Rules

  • Minimum wall thickness: 1.2mm recommended.
  • Text and embossed details: 0.6mm or larger features.
  • Large overhangs may need supports and cleanup time.
  • Use fillets/chamfers on stress points for stronger parts.

File Best Practices

  • Use 3MF when possible for richer metadata and color grouping.
  • Keep file names clear: part-name_revA_qty10.stl
  • For assemblies, upload each part separately unless fused by design.
  • Zip supporting notes/images if tolerances or orientation are critical.
